## Purpose

This fork records my hands-on CSS practice while following The Odin Project curriculum. Each directory contains a focused exercise, starter markup, a target result, and a self-check list.

## Topics Covered

- CSS selectors and the cascade
- Color, typography, and sizing
- Margin, border, padding, and the box model
- Block and inline behavior
- Flexbox alignment and layout
- Responsive composition through small challenges

## How I Use the Exercises

1. Open an exercise directory.
2. Read its local `README.md` and self-check requirements.
3. Open `index.html` in a browser or editor preview.
4. Implement the result in `style.css` without viewing the solution first.
5. Compare the finished work with the reference solution.

No installation or build command is required.

## Repository Note

This repository is a **personal practice fork**, not the original exercise collection. Solutions should stay in personal forks and should not be submitted to the upstream repository.
